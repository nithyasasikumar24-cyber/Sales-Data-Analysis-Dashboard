# 📊 Sales Data Analysis Dashboard

A Data Science project developed during my **14-Day Data Science Internship at Codomax Digital Solutions**.

---

## 📌 Project Overview

This project demonstrates an end-to-end sales data analysis workflow using Python. It covers data preprocessing, filtering, analysis, visualization, dashboard creation, exporting cleaned data, and generating business insights.
